## Step 4: Make Block Fields Non-Editable in Flyout

**Goal**: Prevent accidental field clicks in flyout blocks

**Solution**: Use Blockly's `Field.setEditable(false)` API on fields when blocks are in the flyout

**Files to modify**:
1. `src/actions/enter.ts` - Modify `createNewBlock()` method
2. `src/sticky_mode_controller.ts` - Modify flyout block creation paths

**Implementation**:
1. After `flyout.createBlock(curBlock)` in enter.ts, loop through all fields and disable them
2. In sticky_mode_controller.ts, disable fields when creating flyout blocks for preview
3. Blocks created in workspace automatically have editable fields (default behavior)

**Key Blockly APIs**:
- `block.inputList` - Get all inputs on a block
- `input.fieldRow` - Get all fields in an input
- `field.setEditable(false)` - Disable field editing
