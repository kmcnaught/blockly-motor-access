# Step 2: Add Sound Mute Button to Header

## Overview
Add a mute button in the header that allows users to toggle sound effects on/off. This should work in both grid mode and normal mode. The setting should be persisted to localStorage and reflected in the UI.

## Current Sound Architecture
- Sounds are managed in `maze.ts` in the `MazeGame` class
- Win sound: loaded at `loadAudio()` (line 578-589)
- Crash sound: loaded at `loadAudio()` (line 578-589)
- Sounds are played via:
  - Win: `animateVictory()` (line 1405-1407)
  - Crash: `animateCrash()` (line 1297-1299)
- Audio elements stored as `private winAudio` and `private crashAudio`

## Current Header Structure
- Located in `index.html` (lines 9-28)
- Contains:
  - Title (h1)
  - Center section with mode label
  - Right section with mode toggle, character selector, language select
- Uses flexbox layout with `header-selectors` div

## UI Pattern to Follow
- Existing buttons in header:
  - `modeToggle`: toggles practice/coding mode
  - `pegmanButton`: opens character selector
  - Language selector: dropdown
- All styled consistently with hover/active states

### 2. Add Sound Control to MazeGame Class
**File**: `test/maze-game/maze.ts`
**Changes**:

- Modify `animateCrash()` (line 1297): Check `soundEnabled` before playing crash sound
