How you'll use this app

Any pointer + left-click works, or touch control on a tablet.

Use a mouse, joystick cursor, head mouse, eye gaze or any other assistive tech to control a cursor. Everything can be done with single left clicks only.

Some users prefer to drag blocks; if that’s difficult you can click twice to move.
